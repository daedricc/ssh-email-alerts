# Changelog

## v1.0.0 — 2026-10-11

Initial stable release.

- SSH login and repeated failure notifications from the systemd journal.
- Configurable SMTP/TLS, sender, multiple recipients, thresholds, and timing.
- English and Turkish messages with IANA timezone support.
- Persistent SQLite cursor and delivery queue.
- Configuration validation and process-level TLS sandbox tests.
- Installed version display and manual GitHub release checks.
- No automatic update checks, update emails, downloads, or installation.

See the README for installation, upgrade instructions, and known limitations. A Linux/systemd deployment smoke test for the standalone default installation remains unverified.
